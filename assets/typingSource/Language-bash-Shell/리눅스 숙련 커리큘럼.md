## 1. 파일 시스템 구조

```
/
├── bin       → 기본 실행 파일 (ls, cp, mv 등)
├── sbin      → 시스템 관리용 실행 파일 (root 전용, fdisk, reboot 등)
├── etc       → 설정 파일 (nginx.conf, hosts, fstab 등)
├── home      → 일반 사용자 홈 디렉토리 (/home/유저명)
├── root      → root 사용자의 홈 디렉토리 (/home이 아님!)
├── usr       → 사용자 설치 프로그램 및 라이브러리
│   ├── bin   → 사용자 명령어 (node, git, python 등)
│   ├── lib   → 라이브러리
│   └── local → 직접 컴파일한 프로그램
├── var       → 가변 데이터 (로그, 캐시, 스풀)
│   └── log   → 시스템/앱 로그 파일
├── tmp       → 임시 파일 (재부팅 시 삭제)
├── dev       → 하드웨어 장치 파일 (디스크, 터미널 등)
├── proc      → 실행 중인 프로세스 정보 (가상 파일시스템)
├── sys       → 커널/하드웨어 정보 (가상 파일시스템)
├── lib       → 부팅에 필요한 핵심 라이브러리
├── opt       → 서드파티 소프트웨어 설치 경로
└── mnt / media → 외부 장치 마운트 경로
```

### 개발자가 자주 접근하는 경로

| 경로 | 용도 |
|------|------|
| `~` 또는 `/home/유저명` | 내 작업 공간 |
| `/etc/nginx/` | Nginx 설정 |
| `/etc/hosts` | 호스트 설정 |
| `/var/log/` | 서버 로그 |
| `/tmp/` | 임시 파일 |
| `/usr/local/bin/` | 직접 설치한 툴 |

## 2. 필수 커맨드

### 파일/디렉토리 탐색

```bash
pwd               # 현재 경로 출력
ls                # 파일 목록
ls -al            # 숨김파일 포함 상세 목록
cd ~/project      # 디렉토리 이동
cd -              # 이전 디렉토리로 이동
cd ~              # 홈으로 이동
```

### 파일/디렉토리 조작

```bash
touch file.txt          # 파일 생성
mkdir test              # 폴더 생성
mkdir -p a/b/c          # 중첩 폴더 한번에 생성
cp file.txt backup.txt  # 파일 복사
cp -r dir1 dir2         # 폴더 복사 (-r 필수)
mv file.txt docs/       # 파일 이동 / 이름 변경
rm file.txt             # 파일 삭제
rm -rf folder           # 폴더 강제 삭제 (주의!)
```

### 파일 내용 보기

```bash
cat file.txt            # 전체 출력
less file.txt           # 페이지 단위로 보기 (q로 종료)
head -n 20 file.txt     # 앞 20줄
tail -n 50 app.log      # 마지막 50줄
tail -f app.log         # 실시간 로그 스트리밍 (서버 필수)
```

### 검색

```bash
grep "keyword" file.txt         # 파일에서 검색
grep -r "useState" .            # 현재 폴더 재귀 검색
grep -rn "keyword" src          # 줄번호 포함
find . -name "*.ts"             # 확장자로 파일 찾기
find . -name "*.env"            # .env 파일 찾기
find . -type d -name "node_modules"  # 폴더 타입으로 찾기

# 콤보 (강력)
find . -name "*.ts" | xargs grep "api"
```

### 권한 관리

```bash
ls -l                   # 권한 확인

# 권한 구조: -rwxr-xr-x
# 위치:       [타입][user][group][other]
# r=4, w=2, x=1

chmod 755 file.sh       # rwxr-xr-x (숫자 방식)
chmod +x script.sh      # 실행 권한 추가 (심볼 방식)
chmod -w file.txt       # 쓰기 권한 제거
chown user:group file   # 소유자 변경
```

### 사용자

```bash
whoami          # 현재 사용자 확인
id              # UID, GID 확인
groups          # 소속 그룹 확인
sudo command    # root 권한으로 실행
su - username   # 다른 사용자로 전환
```

### 프로세스 관리

```bash
ps aux              # 전체 프로세스 목록
ps aux | grep node  # 특정 프로세스 검색
top                 # 실시간 프로세스 모니터링
htop                # top의 UI 개선 버전 (설치 필요)
kill 1234           # PID로 프로세스 종료
kill -9 1234        # 강제 종료 (SIGKILL)
jobs                # 백그라운드 작업 목록
```

### 디스크 / 용량

```bash
df -h           # 전체 디스크 사용량 (human-readable)
du -sh *        # 현재 폴더 항목별 용량
du -sh folder   # 특정 폴더 용량
```

### 압축

```bash
tar -czvf backup.tar.gz folder    # 압축 생성
tar -xzvf backup.tar.gz           # 압축 해제
tar -tzvf backup.tar.gz           # 내용 확인 (압축 해제 없이)
zip -r archive.zip folder         # zip 압축
unzip archive.zip                 # zip 해제
```

### 네트워크

```bash
ping google.com                  # 연결 확인
curl https://google.com          # HTTP 요청
curl -I https://google.com       # 헤더만 확인
curl -X POST -d '{}' url         # POST 요청
wget https://example.com/file    # 파일 다운로드
ssh user@server                  # 서버 접속
ssh -p 2222 user@server          # 포트 지정 접속
scp file.txt user@server:~/      # 서버로 파일 전송
```

### 패키지 관리 (Ubuntu / Debian 계열)

```bash
sudo apt update                  # 패키지 목록 갱신 (설치 전 필수)
sudo apt install nodejs          # 패키지 설치
sudo apt remove nginx            # 패키지 제거
sudo apt upgrade                 # 설치된 패키지 전체 업그레이드
apt list --installed             # 설치된 패키지 목록
```

### 서비스 관리 (systemd)

```bash
sudo systemctl status nginx       # 서비스 상태 확인
sudo systemctl start nginx        # 시작
sudo systemctl stop nginx         # 중지
sudo systemctl restart nginx      # 재시작
sudo systemctl enable nginx       # 부팅 시 자동 시작
sudo systemctl disable nginx      # 자동 시작 해제
journalctl -u nginx -f            # 서비스 로그 실시간 확인
```

## 3. 쉘 설정

### 설정 파일

| 파일 | 적용 시점 |
|------|----------|
| `~/.bashrc` | bash 실행 시마다 |
| `~/.bash_profile` | 로그인 시 1회 |
| `~/.zshrc` | zsh 실행 시마다 |

```bash
# 변경 후 즉시 적용
source ~/.bashrc
```

### alias (자주 쓰는 명령어 단축)

```bash
# ~/.bashrc 또는 ~/.zshrc에 추가

alias ll="ls -al"
alias gs="git status"
alias gp="git push"
alias gpl="git pull"
alias ..="cd .."
alias ...="cd ../.."
```

### 환경 변수

```bash
export PATH=$PATH:/usr/local/bin   # PATH에 경로 추가
export NODE_ENV=production         # 변수 설정

echo $PATH                         # 변수 확인
env                                # 전체 환경 변수 출력
```

### Bash 스크립트 기본

```bash
#!/bin/bash
# 첫 줄은 반드시 shebang

NAME="linux"
echo "hello $NAME"

# 조건문
if [ -f "file.txt" ]; then
  echo "파일 있음"
fi

# 반복문
for file in *.ts; do
  echo $file
done
```

```bash
chmod +x script.sh   # 실행 권한 부여
./script.sh          # 실행
```

## 4. Git 필수 커맨드

```bash
git clone URL               # 저장소 복제
git status                  # 변경 사항 확인
git add .                   # 전체 스테이징
git add file.ts             # 특정 파일만
git commit -m "메시지"      # 커밋
git push                    # 원격에 푸시
git pull                    # 원격에서 당기기
git log --oneline           # 커밋 이력 간략히
git branch                  # 브랜치 목록
git checkout -b feature     # 브랜치 생성 및 이동
git merge feature           # 브랜치 병합
git stash                   # 임시 저장
git stash pop               # 임시 저장 복구
```

## 5. Docker 기본

```bash
docker ps                          # 실행 중인 컨테이너
docker ps -a                       # 전체 컨테이너
docker images                      # 이미지 목록
docker run nginx                   # 컨테이너 실행
docker run -d -p 80:80 nginx       # 백그라운드 + 포트 매핑
docker stop container_id           # 컨테이너 중지
docker exec -it container_id bash  # 컨테이너 내부 접속
docker logs container_id           # 컨테이너 로그
docker-compose up -d               # compose 실행
docker-compose down                # compose 종료
```

## 6. 터미널 생산성

### 필수 단축키

| 단축키 | 기능 |
|--------|------|
| `Ctrl + C` | 현재 명령 중단 |
| `Ctrl + Z` | 백그라운드로 보내기 |
| `Ctrl + R` | 명령어 히스토리 검색 |
| `Ctrl + L` | 화면 지우기 (clear) |
| `Ctrl + A` | 줄 맨 앞으로 |
| `Ctrl + E` | 줄 맨 끝으로 |
| `Tab` | 자동 완성 |
| `↑ / ↓` | 이전/다음 명령어 |

### 파이프와 리다이렉션 (리눅스 핵심 철학)

```bash
# 파이프: 앞 명령의 출력을 뒤 명령의 입력으로
ps aux | grep node
ls | grep ".ts"
cat log.txt | grep "error" | tail -20

# 리다이렉션
echo "hello" > file.txt     # 덮어쓰기
echo "world" >> file.txt    # 이어쓰기
cat file.txt 2>/dev/null    # 에러 출력 버리기
```

### history

```bash
history             # 명령어 기록 전체 출력
history | grep git  # 기록에서 검색
!번호               # 특정 번호 명령어 재실행
!!                  # 직전 명령어 재실행
```

### tmux (다중 터미널)

```bash
tmux new                # 새 세션
tmux ls                 # 세션 목록
tmux attach -t 0        # 세션 재접속
# 세션 안에서
Ctrl+B, C               # 새 창
Ctrl+B, N               # 다음 창
Ctrl+B, D               # 세션 분리 (백그라운드)
```
