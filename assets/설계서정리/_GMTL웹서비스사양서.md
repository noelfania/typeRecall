## 5\. 주요 기능 정의

각 기능별 목적, 상세 설명, 유저 플로우 기술

### 5.1 기능 목록

| 기능 ID | 기능명 | 설명  |
| --- | --- | --- |
| F-01 | 회원가입 | 이메일 기반 회원가입 |
| F-02 | 로그인 | JWT 기반 인증 |

### 5.2 기능 상세

#### F-01 회원가입

- **목적:** 신규 유저 생성
- **입력:** 이메일, 비밀번호, 닉네임
- **출력:** 가입 성공/실패 응답
- **예외 사항:** 중복 이메일 등
- **유저 플로우:**

```
User → 회원가입 화면 → 정보 입력 → 서버 검증 → DB 기록 → 완료
```

## 7\. API 사양

REST 또는 GraphQL 사양 정의

### 7.1 REST API 예시

#### POST /api/v1/auth/login

- **설명:** 로그인 API
- **Request Body:**

```json
{
  "email": "string",
  "password": "string"
}
```

- **Response:**

```json
{
  "token": "string",
  "expiresIn": 3600
}
```

- **에러 코드:**
    - 400: 잘못된 요청
    - 401: 인증 실패

### 7.2 GraphQL 예시

```graphql
mutation Login($email: String!, $password: String!) {
  login(email: $email, password: $password) {
    token
    expiresIn
  }
}
```
